# Aurelia 2.0: release notes

Released: 14 March 2019.
Tag: v2.0.0 (signed). Tarball SHA-256 published beside the tag.

Aurelia 2.0 is the first stable release of the 2.x line. The 2.0.0-beta
builds that circulated in 2018 were retired on the same day. This page lists
the 41 changes that landed between 2.0.0-rc3 (February 2019) and the final
tag, and gives the build number of each artifact so a download can be checked
against the published digest.
